CUTOUT STUDIO / A B3N WORKSHOP TOOL

A clean print. An easier build.

  1. Use SVG for scalable vector artwork, or start with the largest original raster image. Crop empty borders before uploading so dimensions match the figure.
  2. The human scale reference is 170 cm tall and is shown only in the preview. Feet inputs use decimal feet (for example, 5.5 ft = 5 ft 6 in). SVG shapes stay sharp as they scale; embedded photos do not. Convert text to paths and embed linked images before uploading. For raster images, check effective DPI: 150+ is a useful target; 75–149 suits distant viewing; below 75 may look soft. These are guides, not guarantees.
  3. Print the scale test. Measure its square: 50 × 50 mm.
  4. Match paper and orientation in the print dialog. Choose 100% / Actual size, no margins and no headers or footers. Choose Save as PDF if desired.
  5. Arrange by row and column. Trim each page's LEFT and TOP dashed lines where shown. Lay those edges over the neighboring pages and line up matching target marks. Tape from behind, then cut the silhouette.

This version preserves source detail. AI upscaling, background removal and automatic silhouette tracing are not included. Browser and printer settings can affect the result.
